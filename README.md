# Site Palabra de Mamá

Projeto estático pronto para GitHub e Vercel. Não usa Node.js, React, pnpm ou comando de build.

## Publicação

1. Extraia o arquivo ZIP.
2. Envie todos os arquivos e pastas extraídos para a raiz de um repositório vazio no GitHub.
3. Na Vercel, importe esse repositório como um projeto novo.
4. Se solicitado, selecione **Framework Preset: Other**.
5. Não configure Build Command, Output Directory ou Root Directory.

O arquivo `index.html` deve aparecer diretamente na página inicial do repositório.
